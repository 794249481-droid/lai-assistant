# LAI助手 V1.4.3

本版本为 V1.4.3，支持 1688 工作台聊天记录导出；优先通过已登录的 1688 页面只读接口分批读取聊天数据。选择多个销售时，会自动将各销售文件合并压缩为一个 ZIP 文件。首次使用时需要由用户填写店铺名称，默认不填入任何公司信息。

## 1.4.3 客户完整记录大文件修复

- 修复客户完整记录超过 Chrome 单条消息 64MiB 时，在最后打包阶段失败的问题。
- 每位客户的记录会先按不超过约 6MiB 的小批次暂存到扩展本地，再由后台统一生成 ZIP；不上传任何聊天内容。
- 导出完成、失败或取消后都会清理暂存的客户聊天内容。

## 1.4.2 自动导出稳定性

- 每日任务开始后会将运行租约持久化；即使 Chrome 的扩展后台被回收或浏览器重启，也不会重复并发导出同一份日报。
- 任务超过 40 分钟未结束会自动释放运行锁，保留失败原因，供 20 分钟补偿检查或下次 Chrome 启动后重试。
- Chrome 启动后只补偿“开启自动导出之后错过的最近一次”日报，不会擅自补跑更早日期。
- 定时任务临时新开的后台聊天页会在完成或失败后自动关闭；用户自行打开的聊天记录页不会被关闭。
- 自动导出仍只生成本地昨日 JSON 压缩包；未新增服务器、账号、上传或数据回传。

## 1.4.1 客户完整记录与精简界面

- 新增两种读取方式：按销售日期记录，或按客户完整记录。
- 客户完整记录会按所选销售与日期范围筛出客户、跨销售去重，再按 20 位客户一批、4 路并发从当前时间向前分页读取；每位客户一个 JSON，统一打成 ZIP。
- 每个客户完整记录保留实际消息发送人；筛选日期只用于识别相关客户，不截断客户的完整记录。
- 每日自动导出与飞书同步设置改为折叠的高级设置，默认界面只显示导出必要控件。

## 1.4.0 分批直连导出

- 每 20 位客户为一个任务批次，批内最多 4 路并发读取，避免逐个打开聊天详情和滚动页面。
- 仅调用当前已登录 1688 页面自身的三个只读接口（员工、会话、消息）；不新增外部服务器、账号或数据回传。
- 接口短暂限流、超时会按 1.5 / 4 / 8 秒重试；直连不可用时自动退回原有页面读取方案，保证任务可继续完成。

## 1.3.8 每日自动导出可靠性修复

- 在侧边栏读取员工列表后，固定勾选五位销售，设置每日时间并保存；插件会每天自动导出前一天的 JSON 压缩包。
- 到点后插件优先复用已打开的 1688 聊天记录页；没有页面时会在后台新开聊天记录页执行任务。
- 自动闹钟、补偿检查与手动测试会分别记录来源；自动闹钟触发后立即注册下一天的执行时间。
- 每日执行时间后 20 分钟会进行一次补偿检查；Chrome 重启或扩展重新加载后也会自检并恢复闹钟。
- 定时设置会显示下次执行时间和上次结果。Chrome、1688 登录状态和电脑需要保持可用。

## 1.3.5 导出提速

- 每次切换客户后，优先读取该次操作触发的聊天接口返回数据；接口数据完整时，不再打开客户详情逐屏滚动。
- 页面读取作为自动兜底，滚动后根据页面实际更新尽早继续，减少固定等待。
- 日志显示每个周期通过接口快速读取和页面兜底读取的客户数量及耗时，便于核验实际提速效果。

## 1.3.0 安全桥接与独立标识

- 页面上下文与内容脚本通过一次性 `MessageChannel` 传递数据，带随机会话标识和来源校验，不再把聊天正文放入全局 `window.postMessage` 消息。
- 清理原始品牌/来源残留，当前独立代号为 LAI助手。

## 1.2.1 员工列表连接修复

读取员工前自动补加载页面脚本并定位聊天查询内嵌框架，解决扩展升级后无消息接收端的问题。新增 scripting 权限用于向已授权的聊天页面补加载脚本。消息按实际 frameId 投递，连接检测可重试，导出指令不会因连接错误自动重复执行。

## 1.2.0 侧边栏

点击工具栏图标打开常驻侧边栏，点击网页不会关闭面板。支持纵向滚动与窄面板布局，要求 Chrome 116 或更新版本。
升级后在扩展管理页重新加载插件，再刷新 1688 页面。侧边栏左右位置由 Chrome 的外观设置控制；如显示在左侧，请切换为右侧。

## 1.1.0 速度优化

- 缓存客户列表滚动位置，读取下一个客户时直接定位；定位失效自动回退全列表查找。
- Excel 图片最多 4 路并发，同一文件中的相同图片 URL 只下载一次，保持消息和图片顺序。
- 单张图片下载超过 30 秒保留错误与链接，继续处理其他图片。
- Excel ZIP 校验采用 CRC32 查表计算，完成日志显示总耗时。
- 仍按员工、7 天周期查询；保留聊天详情等待，避免因盲目缩短等待导致串客或漏记录。

参考：https://github.com/sindresorhus/p-limit （有限并发思路，本插件自行实现，无新增运行时依赖）。
本次未在已登录 1688 页面进行速度对比，实际耗时受客户数量、聊天长度、图片及网络影响。

独立的 Chrome Manifest V3 扩展，只保留 1688 工作台聊天记录导出能力。

## 功能

- 读取聊天记录查询页中的员工账号，支持多选
- 按员工和每 7 天一个周期批量查询，避免单次查询范围过大
- 导出本地 Excel（含聊天图片）或兼容 JSON
- 任务进度、暂停、继续、取消和日志复制
- 可选同步到用户自行配置的飞书多维表格；默认关闭

## 隐私与权限

- 仅匹配 `work.1688.com` 和 `air.1688.com` 的聊天工作台页面。
- 不含生意参谋、数字营销或 `debugger` 权限；使用 `sidePanel` 权限显示常驻侧边栏。
- 图片域名权限仅用于将聊天内图片嵌入本地 Excel；飞书域名权限仅在用户主动开启飞书同步后使用。

## 安装

1. 打开 `chrome://extensions/`，开启“开发者模式”。
2. 选择“加载已解压的扩展程序”。
3. 选择本目录。
4. 登录 1688 后点击扩展图标打开侧边栏，按提示进入聊天记录查询页并导出。
